# 按键对照表

这只遥控器（`CMCC_Voice_Remote`）在 BLE 侧一共上报 9 种 report，实际用到的只有两个：

- **键盘报告**（report `0x01`）：修饰位 + 6 个键码，普通键都在这里，id 前缀 `0x1`
- **消费者报告**（report `0x03`）：16 位 usage，多媒体/功能键在这里，id 前缀 `0x2`

所有 id 都是实测得来的（`LEARN 1` 逐个按键打印，或用 `tools/hci/` 里的脚本从 `btsnoop` 日志核对），
不是从 HID 描述符推测的。

## 一、界面上可以点的 30 个键

`pc/remote_ui.py` 的 `REMOTE` 表用这套 id 定位照片上的物理键，坐标是原图（宽 800 px）像素。

| 键名 | id | 源 | HID usage | 出厂默认输出 |

| 设置 | `0x20EB` | 消费者 | 0x0EB | `Ctrl+C` |
| 静音 | `0x20E2` | 消费者 | 0x0E2 | 静音 |
| 上 | `0x1052` | 键盘 | 0x052 | `↑` |
| 左 | `0x1050` | 键盘 | 0x050 | `←` |
| 确定 | `0x2041` | 消费者 | 0x041 | `回车` |
| 右 | `0x104F` | 键盘 | 0x04F | `→` |
| 下 | `0x1051` | 键盘 | 0x051 | `↓` |
| 菜单 | `0x1065` | 键盘 | 0x065 | `菜单键`（Apps） |
| 返回 | `0x2224` | 消费者 | 0x224 | `Esc` |

## 三、自己查未知键

换了遥控器型号，或者发现某个键没反应时，两步定位：

```text
→ LEARN 1        # 只上报 id，不真的发按键
（按一下那个键）
← L 20EB         # 这就是 id
→ LEARN 0
```

如果连 `L` 行都没有，说明**这个键在蓝牙侧根本不发数据**——TV 键就是这样：

- 10 分钟内音量 + 正常上报 `E9 00 → KEY 20E9`；
- 同一窗口内 TV 键按 3 次，抓包日志里**零帧**，连空白报告都没有；
- 结论：遥控器固件把 TV 键直接交给了红外发射管，蓝牙链路里没有它。物理上救不回来。

广播层面的排查用 `SCANDUMP 1`，可以确认是「设备没连上」还是「连上了但没这个键」。
